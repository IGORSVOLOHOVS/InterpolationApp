## Overview

This project implements and compares 10 different interpolation methods using a rigid **Domain-Driven Design (DDD)** architecture. It demonstrates:
-   **Zero-Cost Abstractions**: Custom `Point` and `Coord` types with no runtime overhead.
-   **Strict C++23 Compliance**: Concepts, `std::expected` for error handling, `constexpr` validation.
-   **Interactive Visualization**: Real-time plotting of data and interpolated results using QtCharts.
-   **Benchmarking**: Integrated `nanobench` performance analysis.

## Features

### Interpolation Methods
1.  **Linear**: Simple straight-line connection.
2.  **Nearest Neighbor**: Step-like picking of closest point.
3.  **Step (Zero-Order)**: Holds value until next point.
4.  **Lagrange Polynomial**: Global polynomial fit (O(N^2)).
5.  **Cubic Spline**: Smooth piecewise cubic polynomials (C2 continuity).
6.  **Akima Spline**: Stable outlier-resistant spline.
7.  **Cosine**: Smooth trigonometric transition.
8.  **Sinc (Lanczos)**: Signal reconstruction.
9.  **Moving Average**: Smoothing filter.
10. **Catmull-Rom Spline**: Local spline with no overshooting.

### UI & UX
-   **Dark Theme**: Modern dark interface (Fusion style).
-   **Performance Metrics**: Real-time execution timing display.
-   **Scalability**: Supports up to **100,000** data points.
-   **Interactive Dock**: Moveable controls for parameters and method selection.

## Architecture (DDD)

The project follows strict layer separation:
-   **Domain**: Core logic, Value Objects (`Point`), Ports (`Interpolator` concept). Zero dependencies.
-   **Infrastructure**: Implementations of algorithms (`LinearInterpolator`, `CubicSpline`, etc.).
-   **Application**: Services orchestrating use cases (`InterpolationService`, `PointGenerationService`).
-   **Presentation**: Qt6-based UI (`MainWindow`) handling user interaction and visualization.
-   **Tests**: Unit tests and benchmarks located in `src/Tests`.

## Building and Running

### Prerequisites
-   **Linux** (fedora/ubuntu tested)
-   **CMake** 3.28 or newer
-   **Qt6** (Core, Gui, Widgets, Charts)
-   **C++23 Compiler** (Clang 16+ or GCC 11+)
-   *Optional*: Graphviz (for documentation), Google Chrome (for report viewing)

### Build Instructions
```bash
# Clone the repository
git clone <repo-url>
cd InterpolationApp

# Create build directory
mkdir build && cd build

# Configure and Build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build .
```

### Running the App
```bash
./InterpolationApp
```

### Running Tests & Benchmarks
```bash
# Run logic tests and benchmarks
./tests_run

# This will generate and open 'benchmark_results_optimized.html'
```
